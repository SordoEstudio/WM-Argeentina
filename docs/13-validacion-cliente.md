# Validación de contenido — WM Argentina Web

Documento para que el equipo de WM Argentina **revise, complete y valide** el contenido de cada página del sitio nuevo antes de publicar.

## Cómo usar este documento

Cada sección tiene una tabla con tres columnas:
- **Dato / Elemento**: qué necesita el sitio
- **Provisorio (origen)**: lo que tenemos cargado ahora y de dónde viene. **Tiene que validarse o reemplazarse antes de publicar.**
- **Qué entregarnos**: qué tiene que confirmar o mandar el equipo de WM

Los ítems marcados `TODO-CLIENTE` son **provisorios**: se muestran en el desarrollo pero no pueden publicarse sin confirmación explícita.

**Prioridad de salida a producción:** todas las filas visibles en el sitio deben estar en ✅ antes de publicar.

Estados: ⬜ pendiente · 🟨 recibido, falta validar · ✅ validado
